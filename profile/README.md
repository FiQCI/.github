The Finnish Quantum Computing Infrastructure (FiQCI) GitHub repository. Below you can find web and development tools provided by FiQCI e.g. for circuit knitting, error mitigation, and QPU resource estimation.

To learn more about FiQCI visi [fiqci.fi](https://fiqci.fi). For documentation on CSC quantum computing services see [here](https://docs.csc.fi/computing/quantum-computing/overview/).
